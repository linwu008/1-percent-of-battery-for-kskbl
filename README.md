# 1% Battery

灾后资源决策模拟器。最后1%的模拟电量、共享环境的Ghost镜像、可复算的成果与消耗。

首版设计见 [项目设计文档](drafts/1012_1pctBattery项目设计文档_v1.md)，实施步骤见 [实施计划](drafts/1012_1pctBattery实施计划_v1.md)。

v0.1 标记开发前设计基线；可玩首版使用应用版本0.1.0与标签v0.1.0。所有能耗是模拟参数，不代表真实设备测试。

## 本地运行

需要 Node.js 24，首次安装依赖需要网络。

```sh
cd app
npm ci
npm run dev
```

打开终端提供的本地网址。完整启动、测试和案例演示方法见 [应用说明](app/README.md)。

## 首版内容

- 四类事件：通信取舍、光信号、安排传达与回联。
- 同一环境的Ghost镜像、实际成本日志、成果优先的评分。
- 随机局与两个可复现案例、结算复盘与JSON导出。
- 经玩家同意后从下一局生效的Ghost习惯成长。
- 无外部模型API、真实短信或位置采集；阅读和思考不推进模拟时间。

`npm test` 执行规则与回放测试，`npm run test:browser` 执行实际浏览器流程，`npm run build` 生成静态应用。所有命令在app目录运行。

## 数据与素材

存档仅保存在浏览器本地，不上传个人信息。UI图形为CSS绘制。React、Vite、TypeScript、Vitest、Playwright等依赖的来源与锁定版本见app/package.json及package-lock.json。AI辅助开发的设计决策与验证记录保留于文档和Git提交。

灵感来自用户指定的人生重开模拟器形式；本项目增加可复算资源成本、共享环境Ghost与因果复盘。相近作品正式引用及比赛提交说明仍需团队最后核对。
