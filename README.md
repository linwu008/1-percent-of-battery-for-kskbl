# 1% Battery

灾后资源决策模拟器。最后 1% 的模拟电量、共享环境的 Ghost 镜像、可复算的消耗与存活概率。

当前玩法见 [项目设计文档 v4](drafts/1013_1pctBattery项目设计文档_v4.md)（v0.4.0：两层权重 + 概率重标定）；
v3 见 [项目设计文档 v3](drafts/1012_1pctBattery项目设计文档_v3.md)（v0.3.0：时间轴 + 自然损耗 + 存活概率），
v2 见 [项目设计文档 v2](drafts/1012_1pctBattery项目设计文档_v2.md)（v0.2.0，抽题制 roguelike），
v1 见 [项目设计文档 v1](drafts/1012_1pctBattery项目设计文档_v1.md)，实施步骤见 [实施计划](drafts/1012_1pctBattery实施计划_v1.md)。

v0.1 标记开发前设计基线；v0.1.0 为可玩首版（160 秒时间轴）；v0.2.0 取消时间轴改为抽题制；
v0.3.0 把「每步 15 分钟」的时间与「自然损耗」加回来，电量随环境变动，结算从打分改为算存活概率；
**v0.4.0 把权重拆成「动作 + 题目」两层并全部藏到结算之后，同时重标定概率模型把事后最优拉回 70% 左右**。
所有能耗与概率是模拟参数，不代表真实设备测试或救援模型。

## 本地运行

需要 Node.js 24，首次安装依赖需要网络。

```sh
cd app
npm ci
npm run dev
```

打开终端提供的本地网址。完整启动、测试和案例演示方法见 [应用说明](app/README.md)。

## 当前内容（v0.4.0）

- **130 道题库**，每局抽 8~12 道（具体几步不告诉玩家）；同一局编号必然复现同一组题。
- 电量 **1.000%** 为唯一硬约束，但它**会随环境变动**：实际耗电 = 标价 × 温度系数 × 信号系数 × 1.3。
- **时间是第二重压力**：每步固定推进 15 分钟，这 15 分钟里电池自然损耗，不操作也掉。
  炎热 + 断网每步自然掉 0.031%，什么都不做十步下去一半的电就没了。
- **结算给存活概率**，不是分数：`P = 被发现 × 被救出 × 撑到救援`，三段各自可解释、可复算。
- **两层权重，且都藏起来**：动作有一档（最重要 ×3 / 较重要 ×2 / 不重要 ×1），
  题目也有一档（×1.5 / ×1.2 / ×1.0，每局抽定）。过程中一律不显示——
  哪一步真正关键得自己判断；结算时才摊开，附逐题对照与完整公式。
- **概率经过重新标定**：事后最优参考线落在 **70.6%**（60 种子实测），
  三种典型打法 42.7% ~ 56.7%，什么都不做只有 4.7%。
- **三条曲线**：事后最优（理论上限，非标准答案）/ 你 / Ghost，直观看见自己哪一步偏了。
- **肉鸽三件套**：6 条环境轴（含「炎热」）、12 个天赋里三选一、Ghost 从 6 种随机性格里抽一个。
- 开局逐字打出这一局的处境；中途可放弃重开；键盘 1–9 选择；结算逐题对照与 JSON 导出。
- 无外部模型 API、真实短信或位置采集。

`npm test` 执行规则与回放测试（62 项），`npm run test:browser` 执行实际浏览器流程（12 项），
`npm run build` 生成静态应用。所有命令在 app 目录运行。

## 数据与素材

存档仅保存在浏览器本地，不上传个人信息。UI 图形为 CSS 与内联 SVG 绘制。
React、Vite、TypeScript、Vitest、Playwright 等依赖的来源与锁定版本见 app/package.json 及 package-lock.json。
AI 辅助开发的设计决策与验证记录保留于文档和 Git 提交。

灵感来自用户指定的人生重开模拟器形式；本项目增加可复算资源成本、共享环境 Ghost 与因果复盘。
