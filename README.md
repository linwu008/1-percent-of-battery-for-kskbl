# 1% Battery

灾后资源决策模拟器。最后1%的模拟电量、共享环境的Ghost镜像、可复算的成果与消耗。

当前玩法见 [项目设计文档 v2](drafts/1012_1pctBattery项目设计文档_v2.md)（v0.2.0，抽题制 roguelike）；
v1 见 [项目设计文档 v1](drafts/1012_1pctBattery项目设计文档_v1.md)，实施步骤见 [实施计划](drafts/1012_1pctBattery实施计划_v1.md)。

v0.1 标记开发前设计基线；v0.1.0 为可玩首版（时间轴制）；**v0.2.0 取消时间轴，改由 1.000% 电量与十道抽题构成约束**。
所有能耗是模拟参数，不代表真实设备测试。

## 本地运行

需要 Node.js 24，首次安装依赖需要网络。

```sh
cd app
npm ci
npm run dev
```

打开终端提供的本地网址。完整启动、测试和案例演示方法见 [应用说明](app/README.md)。

## 当前内容（v0.2.0）

- **130 道题库**，每局抽 10 道（早 3 / 中 4 / 晚 3）；同一局编号必然复现同一组题。
- 电量 **1.000%** 为唯一约束，选项标价精确到 0.001%；成果累积到门槛才成立，上限 12 分权重。
- **肉鸽三件套**：6 条环境轴（灾种 / 信号 / 伤势 / 温度 / 时段 / 随身）、12 个天赋里三选一、
  Ghost 从 6 种随机性格里抽一个并自带随机天赋。
- **没有唯一最优解**：环境耦合让同一个选项在不同局值不同的钱；赌运由种子预先抽定，
  玩家与 Ghost 抽的是同一个数，差异只来自选择。
- 逐字打字显示（打字不推进进度、不耗电）、键盘 1–9 选择、结算逐题对照与 JSON 导出。
- 无外部模型 API、真实短信或位置采集。

`npm test` 执行规则与回放测试，`npm run test:browser` 执行实际浏览器流程，`npm run build` 生成静态应用。所有命令在app目录运行。

## 数据与素材

存档仅保存在浏览器本地，不上传个人信息。UI图形为CSS绘制。React、Vite、TypeScript、Vitest、Playwright等依赖的来源与锁定版本见app/package.json及package-lock.json。AI辅助开发的设计决策与验证记录保留于文档和Git提交。

灵感来自用户指定的人生重开模拟器形式；本项目增加可复算资源成本、共享环境Ghost与因果复盘。相近作品正式引用及比赛提交说明仍需团队最后核对。
