# 1% Battery · v0.1.0

浏览器文字决策游戏。初始10个模拟能量单位，4类事件与Ghost共享环境；每个操作由共用规则计算成本，结果可回放核对。

## 启动

需要 Node.js 24 或更新的兼容版本。测试环境为 Node 24.20.0、Windows、Edge。

```powershell
cd app
npm ci
npm run dev
```

浏览器打开终端给出的本地地址，默认 http://127.0.0.1:5173 。运行无需云API、账号、定位或真实短信权限。依赖首次安装需要网络。

## 验证

```powershell
npm test
npm run build
npm run test:browser
```

浏览器测试默认使用本机 Edge。没有 Edge 时，先运行 `npx playwright install chromium`，再以 `PLAYWRIGHT_CHANNEL=chromium` 运行浏览器测试。测试截图和日志保存在本地 `test-results/`，不上传仓库。

## 演示路线

**案例A：**等人数 → 合并发送 → 等到光信号机会 → 短光 → 等安排 → 纸笔 → 回联 → 等结束。结算应为玩家111、Ghost77。

**案例B：**等过首次窗口 → 短光 → 纸笔 → 补发位置 → 等结束。结算应为玩家28、Ghost99。这里不是推荐策略，用来展示过度等待的后果。

等待遇到新情况会提前停下，需要阅读后再次选择。阅读和思考本身不推进时间。同局再试属于练习，不计Ghost成长。

## 数据与规则

- 能量内部以0.1单位记账，只有主动设备操作扣电；发送途中断网只扣实际消耗。
- 先比较成果价值，再比较余量；结算页显示公式、原始成果和各阶段日志。
- 当两个非练习局符合短光节约条件，结算提供可选成长提案；用户同意后下一局Ghost V2生效。
- 存档只在浏览器本地；损坏记录不加载。导出JSON包含seed、规则版本、Ghost版本、动作与结果，可由 `verifyExport` 重算。
- 相同seed与版本复现同一世界；行动数量不改变随机环境。局内不能查看Ghost未来动作。

所有能耗、环境和人物为模拟，非实际电量测量或救援指导。3–5分钟是体验目标，尚需团队真人试玩调整。

## 结构

`src/game/` 为纯规则与记录，`src/components/` 为页面。事件参数在 `config.ts`、`world.ts` 和引擎中，后续调参必须同步测试与规则版本。`tests/game.spec.ts` 是浏览器流程验收。

使用React、Vite、TypeScript、Vitest和Playwright，版本固定在package-lock.json；保留各依赖许可证。视觉图形由CSS绘制，无第三方图片。开发由AI辅助，规则取舍与测试结果见项目设计文档和提交历史。

v0.1为开发前设计基线；v0.1.0为可玩首版，不代表已获得比赛评分或真人试玩验证。
