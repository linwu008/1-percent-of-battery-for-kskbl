# 本地字体

- Rajdhani SemiBold：Google Fonts / Indian Type Foundry，SIL OFL 1.1。用于数字。
- ReserveSans.woff2：Google Fonts Noto Sans SC 可变字体的字符子集，用于中文。源文件约 17.8 MB，按本项目 src 中的字符裁剪为约 368 KB；新增文案中缺失的字回退到系统中文字体。
- 两套字体的许可证随包保存，字体不单独售卖，不包含游戏专有字体。
