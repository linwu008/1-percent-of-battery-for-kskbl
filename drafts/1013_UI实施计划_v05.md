# v0.5.0 · 灾后应急终端 UI

基线：origin/v0.4.0，682f81f。用户已确认视觉方向并于 2026-10-13 授权开始、创建 v0.5.0 分支和推送。

## 约束与接口

- 视觉：炭黑、雾白细框、薄荷绿状态、琥珀选中、灰紫 Ghost；原创矢量场景，不使用商业游戏素材。
- 表演：中央逐字剧情，底部状态及行动／已知信息／行动记录／确认。选择与提交分离，Enter 跳字不能同时提交，长按不能连续答题。
- 规则：完全保留 v0.4.0 的 130 题、天赋、种子、8–12 步、每步15分钟及自然损耗、两层隐藏权重、概率和事后参考。UI 版本独立于规则版本。
- 成本与已知环境立刻显示，实际结果来自引擎。Ghost 只读当前同步状态。隐藏的权重、下一题、总步数和未来随机结果不能进入局内 UI。
- 用户已批准实施；此次不重复询问数值或审批。工作树开始时干净，独立 v0.5.0 分支承载全部修改。

## Review Focus

- 剧情切换/立即显示切换会不会闪回上一段；Enter、数字、空格、双击和长按能否误提交。
- 已知信息与记录只显示公开状态；两个隐藏权重都不应提前泄露。
- 保留原有引擎、持久化、导出、固定案例和结算回顶行为。
- 不同灾害场景示意不声称真实地图或真实救援指引；百分比与成果均来自原模型。
