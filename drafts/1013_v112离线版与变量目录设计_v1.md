# v1.1.2：离线版与变量目录设计

## 目标与基线

用户要求以同学更新的 v1.0.0 为基础，新建 v1.1.2，提供可下载的本地游戏、游戏变量与策略目录，以及主页双入口动效。

已核对基线：v1.0.0 = a5494ca57d73b00fe7029cccc8c62deda2f909b4。它在 v0.7.0 上更新文档、截图和测试超时，未修改玩法。其 package.json 及界面版本文字仍是 0.7.0；新版本统一展示 1.1.2，游戏规则版本沿用 0.6.0，避免无故使旧存档失效。

用户已明确两种离线形式都做。本稿供实施前审阅；游戏代码尚未改动。

## 一、下载交付

1. Windows x64 免安装 ZIP：解压后双击游戏 EXE，在独立窗口运行；无需安装 Node、启动开发服务器或访问在线站点。使用 Electron 封装本地资源。
2. 单文件 HTML：脚本、样式、字体全部内嵌，下载后在现代桌面浏览器双击运行，断网也能完整游玩。
3. v1.0.0 原版提供上述两份下载，保持玩法和界面；v1.1.2 增强版也提供两份下载，包含新目录和主页动效。下载文件明确标注版本，避免把新增功能误标为 v1.0.0。
4. 成品放 GitHub Releases；仓库 README 顶部展示版本、两种下载按钮和启动说明。大型程序不塞进源码 Git 历史。制作校验文件并记录构建所用提交。
5. 两种形式共享规则与数据。Windows 版存档保存在应用自己的本地目录；HTML 版使用浏览器本地存储，保留现有存储不可用提示与记录导出。两者不声称自动同步存档。
6. 构建缓存和临时输出限定在项目目录。Electron 仅载入打包内容，保持隔离与沙箱、关闭页面 Node 权限及外部窗口导航；无需系统级安装。下载包保留运行时与字体许可。

实现路线比较：只做 HTML 最轻，但不满足独立应用；PWA 仍需浏览器安装入口；采用 Electron + 单 HTML 可复用现有 React 代码并同时满足两种交付。

参考：https://www.electronjs.org/docs/latest/tutorial/security

## 二、变量目录内容

目录为玩家可读规则图鉴，覆盖对局变量及其枚举、单位、取值、作用对象、触发条件、计算顺序与例子，不展示 React UI 状态或构建工具变量。

五个分类：

- 资源与时间：1.000% 电量预算、0.001% 单位、行动费用、自然损耗、剩余预算比例、25/30/35 分钟推进、钟表与累计时间、风险收益和行动标签。
- 环境档案：灾种、网络、伤势、温度、时段、随身物品六轴全部取值；分别说明耗电系数、自然损耗、成果条件和存活计算影响。灾种以剧情作用为主，不能虚构全局数值加成；残电充电宝也不能写成实际给预算充电。
- 策略库：从 TALENTS 读取全部 12 种策略，展示折扣、条件减耗、定额抵扣、成果加点及作用范围；用实际 costOf 等函数生成对比例子。说明策略不能恢复被环境明确阻断的成果，抵扣不会回电，自然损耗不因此打折。
- Ghost 档案：从 PERSONAS 读取六种习惯，展示省电、收益、风险、行动偏好和协作倾向；说明它是预设决策模板，双方同条件计算，各自保留状态，不冒称已经实现学习成长。
- 成果与结算：六类成果、累计门槛、确定与随机收益、三段概率、相对 Ghost 的百分点、关机影响、历史记录，以及事后参考线的用途与搜索近似性质。

数据组织：新增目录适配层，从现有 config、talents、personas、题库与计算函数构造可展示条目。数值尽量直接引用现有常量，不另抄一套；题库环境作用从实际规则扫描出覆盖与例子，不靠猜测。

隐藏信息沿用现行规则：一般作用可解释，但本局题目权重、选项权重和未来随机结果只在结算揭晓。用户已收到是否改变这一规则的问题；没有明确变更前，本稿保留隐藏规则。目录不是本局答案查询器。

## 三、界面与交互

主页将“开始一段人生”调整为用户指定的“开启一段人生”，旁边增加同宽同高的白底深字“变量目录”。开始按钮保留主题绿，两者共享细直角边框、序号和箭头布局。继续上次记录另起一行，避免挤压两个主按钮。

动效：悬停时窄色条横向扫过、边角线延展、箭头短距离移动；按下时轻微位移，页面进入使用短暂遮罩揭示。动效不遮挡文字，键盘焦点同样清晰，系统减少动效时关闭非必要动画。

目录使用灰绿背景、米白内容板、薄荷绿选中态、少量橙金参数标记。宽屏左侧分类，中间条目，右侧详情；窄屏改为分类栏、条目和详情纵排。提供名称搜索、分类计数、返回主界面。详情按“是什么 → 何时生效 → 数值与例子”展开，说明触发条件而非只堆公式。

打开与关闭目录不创建新局、不修改对局或存档；已有未完成对局能继续。目录与游戏页面的键盘事件互不串扰。
